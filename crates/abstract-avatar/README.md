# AbstractAvatar

The shared procedural generator is maintained in the independent
[AbstractAvatar repository](https://github.com/lpalbou/AbstractAvatar).

AbstractTUI presents generic live RGBA frames through `FramePlayer`. Its optional
`avatar` Cargo feature provides the `Avatar` convenience widget using AbstractAvatar.
See [the API reference](../../docs/api.md#frameplayer--live-rgba-media).
